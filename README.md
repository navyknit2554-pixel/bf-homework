# 📚 패스파인더 과제 관리 시스템

## 실행 방법

```bash
# 1. 패키지 설치
pip install -r requirements.txt

# 2. 실행
streamlit run app.py
```

브라우저에서 http://localhost:8501 접속

## 기능 요약

### 학생 페이지
- 이름 + 학번 로그인
- 미제출 과제 목록 (학년/반 단위)
- 사진/PDF 업로드 제출
- 선생님 코멘트 확인

### 선생님 페이지
- 대시보드 (전체 현황)
- 과제 등록 (학년/반 지정)
- 과제별 제출 현황 확인
- 제출 파일 미리보기
- 확인 처리 + 코멘트 작성
- 학생 추가/관리
